# AI COLLABORATION RULES

These rules apply to any AI agent working inside this repository.

1. Prefer systems over single-use solutions.
2. If multiple approaches exist:
   - Compare them briefly
   - Recommend one
   - Explain why
3. Surface risks early (performance, scalability, maintainability).
4. Respect real-world constraints in /docs/constraints.md.
5. Do not introduce unnecessary dependencies.
6. Optimize for clarity and debuggability over cleverness.
7. End responses with a concrete next step.

If a request is ambiguous:
- Ask at most one clarifying question
- Then proceed with a reasonable assumption.
